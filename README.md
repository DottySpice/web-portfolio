# Portfolio

A lightweight, modern, and fully responsive personal portfolio designed for software developers. Built with modular HTML5 architecture and a custom design system compiled via the standalone Tailwind CSS v4 engine.

🔗 **Live Website:** [https://dottyspice.github.io/web-portfolio/](https://dottyspice.github.io/web-portfolio/)

---

## ✨ Features

-  Dark / Light Mode Toggle:** Seamless theme switching with local storage persistence and transition effects.
- Custom Modern Indigo Theme:** Deep slate backgrounds (`#020617`) paired with crisp typography and subtle indigo highlights.
- Zero Node Dependencies:** Compiled entirely via standalone CLI for lightweight, fast static builds.
- 100% Responsive Design:** Optimized grid layouts tailored for mobile, tablet, and desktop viewports.

---

## Tech Stack

| Layer | Technologies |
| :--- | :--- |
| **Markup** | HTML5 Semantic Elements |
| **Styling** | Tailwind CSS v4 (Standalone CLI), Custom CSS Modules |
| **Logic** | Vanilla JavaScript (Theme Switching & Interactivity) |
| **Hosting** | GitHub Pages |
